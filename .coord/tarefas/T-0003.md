# T-0003 — Levar o `main` para a pasta de produção

## Objetivo
O código passa a nascer no GitHub. A pasta de produção (`Regionais - Leandro`, OneDrive) recebe o `main` só por este `.bat`, rodado por quem o Alexandre autorizar.

## Critérios de aceite
1. Baixa o `main` (zip do GitHub ou `git pull` em `C:\bapcentral`).
2. Compara com a pasta de produção e mostra os `.py`/`.bat` que mudam.
3. Grava o backup em `SISTEMA BAP\BACKUP_RELATORIOS\ANTES_<ASSUNTO>_<MÊS><ANO>` antes de qualquer troca.
4. Troca só código. **Nunca** bases, configs `.json` ou dados digitados.
5. Confere byte a byte (hash) os novos e o backup.
6. Sai sem trocar nada se a pasta tiver arquivo mais novo que o do `main` (alguém instalou por fora).
7. Tem simulação (`--simular`) e é testado numa pasta de mentira.
