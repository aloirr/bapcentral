# Contratos (dono: engenheiro-software)

- `relatorio.md`: o contrato do relatório, o dicionário que `relatorios_nucleo.montar(id, ...)` devolve. A primeira versão é escrita na T-0002, a partir do código atual. É a ponte entre os núcleos e qualquer tela: Tkinter hoje, web amanhã.
- `tela-bc3.md`: o contrato visual das telas do site (T-0033): a casca BC3 no PC e o M3 no celular, a faixa, as abas, a grade × popup (`GRADE`), a rolagem por dentro da tabela, os estados, os avisos, os botões, os tokens e os nomes. É a régua de toda tela nova.
- Funções públicas que um módulo oferece a outro, uma por arquivo, quando houver.
