# T-0056 — Rotina diária instala o commit mais novo com 2 h

- **Arquivo:** `atualizar_do_github.py` (engenheiro-software). **ADR:** 0002, §7. **Regra:** 11 do CLAUDE.md.
- **Instale:** obrigatório. O próprio atualizador está em `SO_COM_INSTALE`.

## Funções
| Função | Pura | O que faz |
|---|---|---|
| `escolher_commit_maduro(commits, agora, instalado=None, horas=2.0) -> EscolhaCommit` | sim | Percorre a lista da API (o mais novo primeiro). Devolve `maduro` (sha, data), `ja_instalado`, `instalado_mais_novo` ou `nenhum_maduro`. Item sem SHA válido é ignorado; item sem data conta como novo. |
| `horas_desde(data, agora) -> str` | sim | `"2,3"` para o log. |
| `rodar_diario` | não | Com o HEAD maduro, nada muda (3 requisições pagas). Com o HEAD novo, 1 chamada a `commits?sha=main&per_page=100` e escolha; os limites 2 a 5 valem para o escolhido. |

- `commit_maduro` e `versoes_batem` continuam: a primeira é usada na escolha; a segunda é o limite 3 do commit escolhido, **só igual** (regra 11 do CLAUDE.md; afrouxar é governança, decisão do Alexandre).

## Códigos (sem código novo)
- 10: nenhum commit maduro, ou o instalado é mais novo que o maduro.
- 0: o maduro já está instalado.
- 15: a lista de commits falhou ou a resposta não é uma lista.
- 12: a web do escolhido é diferente da do site (mais nova ou mais velha), ou o site não respondeu.
